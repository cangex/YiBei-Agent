# 益贝医疗智能体 · 离线桌面版 1.1.0

## 安装与启动

适用目标：Windows 10 / Windows 11 64 位。双击 Setup.exe，选择安装目录，按向导完成安装。无需 Node.js、Python、开发工具、服务器或网络。通过桌面“益贝医疗智能体”快捷方式启动。

本测试安装包未做代码签名。Windows 可能显示“未知发布者”或 SmartScreen 提示；仅在确认安装包来源并校验 SHA-256 后按所在机构的安全策略处理。不要关闭系统安全防护。正式商业分发建议由软件所有者提供代码签名证书后重新构建。

## 使用项目

1. 首页保留四个入口，第二个进入重建，第三个进入双微平台；第一、第四个为尚未开放的产品入口。
2. 点击顶部“新建”，输入项目名称。默认加载演示用测试 STL。
3. 在重建页选择或拖入 STL；支持二进制及文本 STL。限制为 24 MB、20 万三角面，超过限制请先用网格软件精简。
4. 启动重建，依次观看轮廓解析、全域扫描、缺陷重建（包含降噪）、精度校验和模型输出。四个观察屏联动显示当前区域的演示处理；完成后可切换材质与修补量视图。进入双微 AI 设计时，使用同一原始模型继续演示，不将其冒充实际修复输出。
5. 项目每秒自动保存，也可点击“保存项目”或按 Ctrl+S。未完成流程下次打开会从保存的进度继续。最小化时暂停计算时间推进与主要渲染工作。
6. “打开”选择项目文件夹内的 project.yibei。软件启动时自动恢复最后打开的项目。
7. 通过顶部画质选择“精细 / 均衡 / 节能”。更改画质会重建三维场景并保留流程状态。系统缩放由 Windows 管理；视图菜单支持缩放与全屏。

## 数据、备份与升级

Windows 默认数据位置：%APPDATA%\YiBeiMedical\

- projects\<项目标识>\project.yibei：版本、模型校验值、演示进度和三套候选区域配置。
- projects\<项目标识>\models\<SHA256>.stl：导入时保存的原始模型副本。
- settings.json：上次项目位置和渲染质量。
- logs\desktop.log：本地运行日志，超过 2 MB 后滚动保留一份。

菜单“项目 → 打开项目所在目录”可直接定位。备份或转移时，复制完整项目文件夹（project.yibei 与 models 目录一起），不要只复制一个文件。软件不会修改最初导入的外部 STL，且不会上传客户文件。

手动升级：保存并关闭软件，运行新版安装包并覆盖安装。项目和设置不在安装目录内，升级不会主动覆盖它们。卸载默认保留用户数据；如需彻底删除，请先备份，再手动处理上述 YiBeiMedical 数据目录。

项目版本为 1。遇到未来不兼容版本时拒绝打开，不静默改写。模型缺失或校验失败时保留原文件并明确提示。软件异常退出后可重新启动，最多可能损失上次自动保存之后的进度。

## 演示范围与故障处理

当前重建、仿真和指标是前端确定性演示，不执行真实 AI 推理、有限元或临床精度验证。保存的是原始 STL 与演示状态；本版没有输出真实修复后 STL，generatedData 为空。

如果模型加载缓慢，请尝试均衡或节能画质，并降低模型面数。若出现空白或图形错误，请更新厂商显卡驱动并重新启动；错误持续时提供日志与软件版本给维护人员。不要把患者数据放入公开问题报告中。

Windows 实际测试范围、构建结果和未验证项以随安装包交付的验证报告为准。
