# Windows 实机验收清单

此清单不是已完成报告。请在 Windows 10 x64 与 Windows 11 x64 上分别执行，记录版本号、OS build、CPU/GPU/驱动、内存、DPI、安装包 SHA-256。不能把 macOS Electron、跨平台打包、Windows Server CI 或软件渲染结果称为客户 Windows 实机测试。

## 安装 / 离线 / 卸载 / 升级

1. 用空白 Windows 用户或可丢弃的测试 VM；校验安装包 SHA-256，并查看实际签名状态。
2. 断开外网（可保留操作系统回环网络），再运行安装器；确认无需下载组件。测试默认路径以及带中文、空格的自定义路径。
3. 从桌面快捷方式和开始菜单分别启动，确认不弹终端。重复启动只聚焦同一窗口。
4. 保持端口 3000 被其它程序占用，软件仍能自动选择新端口。
5. 新建中文名称项目，选择及拖入中文文件名 STL；完成两个产品全部流程，保存方案 3，再关闭软件。
6. 保持断网，重新启动并打开项目；核对模型 SHA-256、进度、全部区域配置和选中方案。测试复制整个文件夹到 U 盘再打开。
7. 备份项目，在程序运行时启动安装器，确认先合理关闭程序；执行同版本覆盖安装，再测试下一版本覆盖安装。更新前后项目文件/模型哈希一致，设置保留。
8. 卸载：程序文件和快捷方式正常移除，用户项目仍在；重新安装可重新打开项目。客户数据不可在测试中误删。
9. 测试损坏 project.yibei、丢失 models、修改模型字节、不支持版本、只读目录与磁盘空间不足，确保明确反馈，不覆盖有效项目。
10. 强制结束程序后再次启动，应无残留监听进程，能从最近自动保存恢复。

## 图形与性能

- 三个页面，默认磨牙与测试 STL，重建扫描 / 四类异常局部修复 / 精度校验 / 前后对比。
- 双微基线：力学载荷、波动液膜、微生态、多场融合；联合设计、三个并行候选、复算、收敛、方案切换和旋转缩放。
- 100%、125%、150%、200% 系统缩放；窗口最小尺寸、最大化、全屏、多显示器切换。
- 精细、均衡、节能画质，系统减少动态效果。
- 连续三次完整流程与十次跨页切换后，观察工作集、JS heap、WebGL 资源与帧率是否趋于稳定。
- 记录冷启动/首个模型的耗时、特效稳定期间的帧时间分布、长帧、最小化后的 CPU/GPU 占用。不要将截图抓取或安装包压缩期间的瞬时帧率当成基准性能结论。

开发人员可运行 `pnpm desktop:test` 和 `pnpm desktop:qa`（需要开发依赖）。客户端安装验证必须另外针对实际打包的 EXE 执行，不能只测试 Electron 开发入口。
