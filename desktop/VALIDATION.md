## 性能与资源检查

`dist-desktop/qa/performance-report.json` 记录了额外六轮“已完成重建 → 双微 → 首页”切换。每次回到首页只存在一个 canvas，手动触发垃圾回收后的 JS heap 从 5,214,924 字节趋于 8,639,808 字节，后面三次约 8.53 / 8.67 / 8.64 MB，没有观察到持续线性累积。此测试不能排除所有 GPU 驱动资源问题。

在本机均衡画质、已完成双微场景稳定显示时，五次连续帧率样本为 59.9 / 60.1 / 59.9 / 60.0 / 60.0 FPS，22 draw calls、16 geometries。完整流程冷加载和截图期间出现较低瞬时帧率；这些样本不应被表述为“全流程恒定 60 FPS”。客户 Windows 显卡表现仍需另测。
